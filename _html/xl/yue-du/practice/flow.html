雅思阅读第05讲 流程图/图形填空（考点自测）

这两类题位置固定、范围小，练"不拘一格定位" + 动词线索。做错返回 问答精要。

题型特点

Q1流程图填空的性价比为什么高？
提示：位置在哪？
显示答案 + 考点
答案：位置固定（通常在文章中部/局部），范围小，答案基本是原文词
流程图对应文章一小段实验/环节描述，范围固定，好定位、好得分。
Q2"不拘一格定位法"是什么？
提示：别死等原文原词。
显示答案 + 考点
答案：题干词可能被替换，用任意独特词（数字/大写/怪词）都能定位
不必等题干原词；只要是独特的定位信号（如 1996、triangular），抓到一个就能切入。

定位与取舍

Q3动词为什么是流程图填空的核心线索？
提示：流程图连的是动作。
显示答案 + 考点
答案：动词串联实验步骤，答案多为步骤中的名词宾语
看图上的动词（collect / measure / record），找到对应原文动词，宾语就是答案。
Q4图形填空和流程图填空的区别？
提示：图形上有什么？
显示答案 + 考点
答案：图形填空图上标数字/部位名称，答案贴在图形部位旁；流程图按步骤顺序填空
图形填空像"看图贴标签"，流程图像"串联步骤"。两者都按题号顺序出题。
Q5乌龟实验真题：答案受"最多2词"限制时，怎么取舍？
提示：原文是 triangular graph paper。
显示答案 + 考点
答案：限定形容词 triangular + 核心名词 graph
原文词组超过字数上限时，保留限定形容词 + 核心名词：triangular graph，别贪多。
