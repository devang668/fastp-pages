# 识命·用命·破命
- 一句话定位
  - 披着赛博朋克皮的命理学/因果论普及书
  - 把命理、因果、佛法翻译成「系统/代码」语言
- 故事框架
  - 主角：破产/离异/丧亲的中年男人
  - 触发：遇上神秘系统 AI「元一」
  - 元一三连锤
    - 自由意志是幻觉（破产离异丧亲全是强制剧情点）
    - 努力是阻尼测试（让你永远不怀疑世界是假的）
    - 想躺平 = 被痛觉抽回仓鼠轮（饥饿/疾病/催债/亲人遭罪）
  - 全书结构：识命 → 用命 → 破命
- 核心一：认识自己（识命）
  - 三个出厂参数
    - 底层驱动（日主）= 五行偏好：木火土金水
    - 初始带宽（格局）= 身强身弱，决定承载力
    - 默认轨道（宿命/局）= 财局 / 官局 / 印局
  - 痛苦的根源
    - 拖拉机非要装 F1 引擎 → 车毁人亡
    - 身弱去创业 / 印局去做销售 = 硬件过载
  - 命 vs 运
    - 命 = 出厂配置（静态，改不了）
    - 运 = 大运 / 流年（动态，限时权限开放）
    - 风口来了疯狂掠夺算力
    - 风口过了立刻减速、卸下涡轮、回到安全区
    - 不懂的人 = 继续踩油门冲向悬崖
- 核心二：婚姻（算力账本）
  - 爱的本质
    - 系统为防止 NPC 自杀的「高维补丁」
    - 多巴胺黏合剂，绑住你不让你拔电源
  - 一见钟情的真相
    - 双方算力缺陷互补
    - 系统强制释放多巴胺/催产素绑定
  - 婚姻的算力账本
    - 势均力敌 ≠ 门当户对 = 算力对等
    - 谁占谁便宜系统都记得
    - 失衡 = 联合服务器熔断
    - 单向索取 = 系统罚单（出轨/破产/暴病）
  - 嫁入豪门 / 入赘的真相
    - 物质算力 ≠ 白嫖
    - 必须用情绪算力 + 忠诚服从置换
    - 尊严权限 / 自由意志 = 标价
    - 命运的馈赠早已暗中标好价格
  - 三条总纲
    - 爱是系统补丁
    - 婚姻是联合服务器
    - 借运必须交出核心权限
- 核心三：成就自我（储蓄罐 → 路由节点）
  - 两种人
    - 老实人 = 被动失血，没有护盾
    - 顶级玩家 = 主动分发护盾，系统官方授权
  - 储蓄罐陷阱
    - 匮乏代码：赚到就锁死
    - 系统核心法则 = 能量守恒 + 持续流动
    - 锁死 = 阻碍算力流转的血栓
    - 系统派「白细胞」来清理
  - 破局：布施 = 申请扩大宽带
    - 财施
      - 不是捐穷人
      - 真正财施 = 商业帝国 / 创造就业 / 投资科技
      - 你 = 合法的「发薪机器」
    - 法施
      - 教认知 / 智慧 / 技术
      - 帮人停止无意义内耗
      - 升级为「管理员级别」
      - 圣人和宗师 = 顶级补丁分发者
    - 无畏施
      - 全员恐慌时你保持冷静
      - 情绪稳定 = 共享护盾
      - 被标记为「核心稳定锚」
- 附录：识别贵人的三个物理特征
  - 低延迟与高稳定性
    - 遇事 CPU 不满载
    - 立刻运算最优解
    - 识别点：毛骨悚然的平静
  - 高数据吞吐率
    - 不废话、立刻执行
    - 第二天拿出测试版本
    - 识别点：粗糙但已跑通
  - 系统兼容与能量溢出（最核心）
    - 靠近 = 内心安定、头脑清晰、充满力量
    - 远离 = 极度疲惫、心慌、焦虑、自我怀疑
    - 立刻切断所有联系方式
- 三条老道理
  - 能量守恒（因果不虚）
  - 不囤积（布施即自保）
  - 顺势而为（识命不躺平，借运要等价）
