config · 出厂配置

你的 出厂配置单

从你被初始化的那一刻，这三个参数就写死在你的底层代码里 —— 这就是「八字」。

参数 01 · 底层驱动
日主 / 五行
木（生发）· 火（热烈）· 土（厚实）· 金（肃杀）· 水（流动）
决定你天然倾向执行什么指令。
参数 02 · 初始带宽
格局 / 身强身弱
内存大小。身弱的人中彩票都会烧毁硬件 —— 不是不配，是承载不住。
参数 03 · 默认轨道
宿命 / 局
财局（算力交换）· 官局（权限管理）· 印局（数据存储）
你最该待的位置。
明明是拖拉机，你非要给它装上 F1 赛车的引擎 —— 车毁人亡。

env · 命 vs 运

命 + 运

你的硬件（命）是静态的，但系统环境（运）是动态的。

// 命 — 静态
拖拉机
出厂配置改不了。你的五行偏好、内存大小、默认轨道 —— 一出生就写死。
×
// 运 — 动态
涡轮增压
大运 / 流年 = 系统周期性补丁 + 限时权限开放。风口来了，拖拉机也能跑赢 F1。
风口过了，你懂不懂得立刻减速、卸下涡轮、回到你该待的安全区域？
不懂的人，会在权限被收回的第二天，继续踩着油门冲向悬崖。

upgrade · 三大布施

破局：布施 = 扩大宽带

在代码层面，布施是主动向系统申请「扩大宽带」的黑客指令。不是道德表演，是合法升级。

布施 01 · 财施
商业 / 投资
不是捐穷人。建商业帝国、创造就业、投资科技。你 = 合法的「发薪机器」，系统奖励你成为帝国的王。
布施 02 · 法施
教认知 / 技术
把底层运行规律教给迷茫的 NPC，停止他们的无意义内耗。圣人和宗师 = 顶级「补丁分发者」。
布施 03 · 无畏施
情绪稳定共享
全员恐慌时你保持冷静 = 帮系统降温。被标记为「核心稳定锚」，任何灾难都无法摧毁你。
