雅思阅读第09讲 信息匹配（考点自测）

信息匹配练"五届策略"与"功能词"识别，注意同词≠同段。做错返回 问答精要。

题型特点与策略

Q1信息匹配题（段落信息匹配）有什么特点？
提示：题目数量 vs 段落。
显示答案 + 考点
答案：选项是段落字母，题干是信息点；大多乱序、可能 NB 重复使用
把题干理解为"信息点"（不是原词），回文章按段落检索。
Q2以五题为界的策略是什么？
提示：先读文章还是先读题。
显示答案 + 考点
答案：题目 > 5 道 → 先读文章逐段检索；题目 ≤ 5 道 → 先读题干再通读
题少带题读省时间；题多先通读文章，边读边对照剩余题目。

功能词与法宝

Q3题干里的"功能词"有什么用？
提示：example / problem。
显示答案 + 考点
答案：功能词提示要找的段落类型（含例子/问题/对比的段落）
题干出现 a number of examples → 选段落必须真的有一串例子；单个例子不算。
Q4做题"法宝"是什么？
提示：别只等原词。
显示答案 + 考点
答案：同词异义替换 + 段落主题扫描
扫每段首句/主题句，对照题干信息点；关键词同段出现还可能是陷阱（同词≠同段）。
Q5西红柿真题：NB 表示什么？
提示：注意题目开头说明。
显示答案 + 考点
答案：NB = 一个段落可能被选多次
有 NB 时段落可重复选；C 段西红柿真题用两次就是实例。
