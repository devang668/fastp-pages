雅思听力全面知识清单

把老师 8 讲里讲过的每一个考点浓缩成词库清单。必考内容必须背熟，选考内容眼熟即可；配合每讲自测题检验掌握程度。

一、考试框架与计分

维度Part场景 / 内容
生存英语 · 对话Part 1租房、超市、旅游问询（Form 个人信息表主战场）
生存英语 · 独白Part 2导游介绍景点 / 文化 / 规定（地图、表格、配对高发）
学术英语 · 对话Part 3同学讨论选课作业、师生答疑做 research（配合 both agree）
学术英语 · 独白Part 4学术讲座（天文、纳米、微生物、商业；填空主战场）
计分：40 题。目标 7 分需做对 30+（约 75%）；8 分需 35+（87.5%）。总分四科平均，单项提分对总分贡献有限，四科雨露均沾。

三类 9 题型：主观题（写单词）Form / Table / Note / Sentence Completion；客观题（写字母）单选 / 多选 / 配对；混合题地图题（A-F 字母是配对、没字母是填空）。

二、必考一：数字（至少 3 道，必须全对）

数字串（电话 / 账号）

  • o 是 0 最常见的读法（别等 zero）；分组报：3-3-3 或 4-4-4。
  • 相同数字连读：double=两个（double nine = 99）、triple=三个。
写法读法说明
0zero / oo 更常见，字符串里优先
99double nine两个相同数字连读
444triple four三个相同数字连读
0748 993 064oh seven four eight, double nine three, oh six four按 3-3-3 分组报

teen 与 ty（鼻音辨音）

类型结尾例辨别
-teen 十几13-19fifteen / thirteen有"过鼻子"的鼻音
-ty 几十30-90fifty / thirty没有鼻音

价格、年份、大数

  • 钱数：整数 + 单位（pounds），小数直接读数字：4.45 = four pounds forty five；penny 复数不规则 = pence。
  • 年份：980 = nine hundred and eighty（eight 与 and 连读，常听成 990/919/918）；雅思最大考到 2020 = two thousand and twenty。
  • 单位帽子法：三位一组，每组按百位读，扣单位帽子 hundred → thousand → million → billion。

三、必考二：人名拼写（送分 1 题）

-内容
姓last name / family name / surname；title（Professor）后面跟姓
名first name（Professor + Amy 是错的）
易混字母g/j、m/n、a/e、l/o（老外读 l 很"妖娆"，像 o）
做题铁律不要盯单个字母，要看整个单词（Jay 不可能拼成 Gay）

四、必考三：日期（12 月份 + 7 星期，老师点名要整理）

写法铁律：日期写基数词（31 不是 31th），年放最后；月日顺序随意（Feb 22 或 22 Feb 都对）。简写 = 前 3 字母 + 点（Jan.），不能少点、不能多字母。

12 个月份（全称 + 简写）

月份简写月份简写
JanuaryJan.JulyJul.
FebruaryFeb.AugustAug.
MarchMar.SeptemberSep./Sept.
AprilApr.OctoberOct.
MayMay（无简写）NovemberNov.
JuneJun.DecemberDec.

高频易错：February（中间有 r 的音）、Tuesday / Wednesday / Thursday（长得像，考得多）。

7 个星期（周一至周日全整理）

中文英文注意
星期一Mondayday 结尾，周日外全带 day
星期二TuesdayTuesday / Wednesday / Thursday 最易混
星期三Wednesday拼写吞音：Wen-s-day 按拼写记
星期四Thursdayth 开头
星期五Friday-day
星期六Saturdayur 拼写
星期日Sunday一周之首其实是 Sunday

补充答案词

  • midday 正午 12 点、midnight 午夜 12 点。
  • 月份/星期读题时先默读一遍，定位时才能跟上。

五、选考一：时间

规则内容
只有一种读法六点半 = six thirty，没有 half past six / a quarter to
逢五逢十30 / 15 这类，不会考 02:02 细碎时间
o 的读法5:05 = five o five
选考规则考了数字题就不考时间题（两者选考其一）

六、选考二：地址（复合考点）

  • 小地址在前、大地址在后（和中文相反）：Number 5 Zhongguancun South Street, Beijing, China。
  • 挖门牌号 = 数字考点；挖路名 = 人名拼写考点（会拼给你听）。
  • 路名高频：street / road / avenue / lane；注意 North/South/East/West 方向词挂路名（South Street）。

七、地图题词库（考频高、方法性强）

三类图

类型特征考频
街道型城市街道 + 沿街建筑相对较少
区域型公园/植物园/农场，常配罗盘高
平面结构图户型/地下室/船舱（双实线=墙、小斜杠=门）高

路线词库

动作表达
直走go straight / go straight ahead / go along the road
转弯turn；take the first/second turning on your left/right
经过/穿过pass；go through（穿门/入口）；cross / across（从上面过桥）；through（桥下/管道）
朝某方向go towards（towards the bridge and turn right just before it）

8 方位（必须会）

基本四向
north / south / west / east
四斜向
northeast / southeast / northwest / southwest
方位词
opposite / in between / at the end of / facing you
场景词
gate / entrance / cafe / dormitory / office / playground / court / stairs / cloakroom / balcony
交通词
traffic light / roundabout / clockwise / anticlockwise
入口出口
way in / way out（英式）；entrance / exit（美式）

辨音陷阱与铁律

  • corner（转角）vs corridor（走廊）——高频辨音陷阱，听错直接选错房间。
  • 远近相对、左右绝对：比例尺让图上的远近失真，但以起点为参照，左/右是绝对的。
  • 有没有罗盘决定描述方式：有罗盘用东西南北、没罗盘一定用左右。
  • 找起始点（地下室图的入口必是楼梯）→ 默读定位词 → 按顺序听定位词后的描述。

八、表格题信号词（Table Completion）

信号词用途 / 场景
it's called后面接"名字"答案（the great migration）
it's on上映 / 地点（it's on in theater C）
take place发生地点（take place in the exhibition room）
display / 3:45 / on the lawn同一活动的多个信息一句话连排
  • 题目按顺序、信息点乱序：表格同一行的 name / location / type / time，音频可能跨列跳着讲。
  • 字母编号：单元楼不叫"1 单元"叫 A 单元；影院不叫"1 号厅"叫 theater C，别把 C 听成 Sea。
  • 时间逢五逢十（3:45 不会考 3:03）。

九、单选题限定词 4 类（筛选正确选项）

类型标志词例子
时间限定now / future / 时态（has been done）currently（现在）
频率频度限定most frequent / only / limitedapproximately（大约）
地点限定具体地点名词in the restaurant
名词限定形容词 + 名词（覆盖最广）reduced price（降价）
  • 定位词 = 句子主干（主谓宾），负责"报时"（题来了）；限定词负责"筛选"。
  • 短选项有陷阱：短选项（627/628/629）三个都可能被提到，靠同义替换选（approximately ≈ about）。
  • 长选项找不同：只抓核心差异点（government / family / former employer 三个主体）。
  • 正确选项通常都有同义替换；听到原词的往往是干扰项。
  • 读题两步走：先读完所有题干（划限定 + 定位），回头再看选项；定位成功后再读选项也来得及。

十、多选题排除法（5 选 2 或 7 选 3）

多选题 5 个选项全部都会出现且乱序，唯一应对是排除法，划掉带下面三特征的选项：

错误特征例子
带否定词it wasn't / I didn't / don't generally —— 明确否定，直接划掉
不符限定题干限定（如时间/地点）对不上
张冠李戴原文说"幸运的是没下雨"，选项写"在雨中等待"
  • 正确项必有同义替换：stand outside and queue → wait to enter the exhibition。
  • 多选 5 个选项全出现且乱序是常态——看到全出现别慌，直接排除。
  • 选 2 个时 2 个答案可能在原文里是相连的两句话，听完才定。

十一、填空题四步法 + 逻辑信号词

步骤内容
1读字数要求（ONE WORD / NO MORE THAN TWO）
2读标题定场景（Section 4 是学术独白）
3空格前后各找一个定位词，"双定位词"夹住空格 + 常识预测词性词义
4定位词出现才 focus，之前的不必全懂

逻辑信号词

功能信号词
列举要点for one / in addition
转折对比however / whereas
除外apart from
并列连接and / also / both / or（等着听并列结构答案）
  • 同义替换三大类：定语从句（先行词被挪位）、代词指代（this/that 代替定位词）、A of B 语序变化（原文 B A）。
  • 生僻学术词永远不做考点——不懂的单词不慌。

十二、配对题考点（收官题型）

Part考法
Part 2单层汉堡：干扰信息 或 同义替换（考干扰就不考同替）
Part 3双层汉堡：同义替换 + 干扰 + both agree（双方都要同意）
  • 三步法：读题目要求 → 读题干（默读发音）→ 读选项（预判替换/划核心词），题干原词定位后抓干扰或同义替换。
  • 错过一题后面可能连续错——节奏 > 纠结，漏题直接跳过。
  • 常用同替：teacher ↔ tutor；building ↔ construction / construct；area ↔ location。
备考节奏：先背熟必考三类（数字、人名、日期）词库，再做 7 大题型自测；错题回问答精要复习；精听两步法（第一遍做题、第二遍挖空听写）巩固核心词汇。
