雅思听力8讲 第02讲 Form Completion 个人信息表（考点自测）

题目全部来自课程里老师讲过的真实考点。先独立做题，再点「显示答案 + 考点」对照；做错的返回对应 问答精要 复习。

数字串：电话号码 / 账号（必考，至少3道）

Q1听电话号码：
音频：My number is oh seven four eight, double nine, three oh, six four. (oh = 0)
提示：电话数字按 3-3 或 4-4 分组报；0 常读成 oh；相同数字连读用 double / triple。
显示答案 + 考点
答案：0748 993 064
数字串按 3-3-3 分组；o(oh) 是 0 的常见读法，别等 zero；double nine = 99。紧跟节奏写，别卡在单个数字上。
Q2听银行卡账号（16 位）：
音频：It is six triple four two, oh double eight, one three five, nine seven double two.
提示：triple 表示三个相同数字。
显示答案 + 考点
答案：6444 2 0 88 135 9722
triple four = 444；oh double eight = 0 88；double two = 22。分组听写，整串写完再复查位数。
Q3听价格：4.45 英镑怎么报？
音频：That would be four pounds forty five, please.
提示：先整数+单位，小数直接读数字。
显示答案 + 考点
答案：four pounds forty five
钱数读法：整数 + 单位(pounds)，小数直接读数字，不读 point；penny 复数不规则 = pence。
Q4区分 15 和 50：
音频：The number I said was fifteen, not fifty.
提示：teen 有鼻音，ty 没有。
显示答案 + 考点
答案：15 = fifteen（鼻音结尾），50 = fifty
-teen 结尾有"过鼻子"的鼻音，-ty 没有。靠鼻音分辨 13-19 vs 30-90，人名/日期/门牌里常考。
Q5听年份 980：
音频：It was built in nine hundred and eighty.
提示：eight 以元音开头，和 and 连读。
显示答案 + 考点
答案：980 = nine hundred (and) eighty
eight 与 and 连读成 /neɪn hʌndrəd ənd eɪti/，大批考生听成 990 / 919 / 918。雅思最大考到 2020 (two thousand and twenty)。

人名拼写（必考，送分 1 题）

Q6听人名拼写：
音频：My last name is spelled G-R-E-E-N, first name Amy.
提示：姓=last/family/surname；title 后面跟姓。
显示答案 + 考点
答案：last name: Green；first name: Amy
先分清 first/last/family/surname；易混字母 g/j、m/n、a/e、l/o。看整个单词而不是单个字母——Jay 不会拼成 Gay。
Q7易混字母辨音：以下哪组最容易听混？
提示：老师在课上点名了 4 组。
显示答案 + 考点
答案：g/j、m/n、a/e、l/o
老外读 l 很"妖娆"，像 o；g/j、m/n、a/e 也易混。人名拼写题靠"整词记忆 + 上下文"纠错，别死盯字母。

日期 / 时间（必考 日期，选考 时间）

Q8日期书写规范：31th March 对吗？
提示：老师强调过写法。
显示答案 + 考点
答案：不对，写 31 March（基数词），不写 31th
日期写基数词：Feb 22 或 22 Feb 都对，年放最后；"31th March" 是错误写法直接丢分。月份简写前 3 字母+点(Jan.)。
Q9听力里的时间只有几种读法？
音频示例：six thirty / five o five
提示：老师强调雅思时间和现实约会的规律。
显示答案 + 考点
答案：六点半 = six thirty（只有这一种读法），5:05 = five o five
雅思时间只有一种读法：six thirty，没有 half past six；逢五逢十，不考 02:02 这种细碎时间；o 读法：5:05 = five o five。
Q10选考规律判断：
提示：数字题和时间题的关系。
显示答案 + 考点
答案：考了数字题就不考时间题（两者选考其一）
数字、人名、日期是必考（至少3道必须全对）；时间、地址是选考，考数字题时通常不再考时间题。

地址（选考，复合考点）

Q11听地址：
音频：It is Number five, Zhongguancun South Street, Beijing.
提示：英文地址从小到大。
显示答案 + 考点
答案：Number 5 Zhongguancun South Street, Beijing
英文地址小地址在前、大地址在后，和中文相反；地址是复合考点：门牌号=数字考点，路名=人名拼写考点（会拼给你听）。
Q12一句话总结本讲考点：送分题要全对的是？
提示：老师说"送的分必须拿到，别客气"。
显示答案 + 考点
答案：数字、人名、日期（必考 3 道）+ 训练素材：20 分钟基础能力专项音频
必考：数字、人名、日期，至少 3 道必须全对；选考：时间、地址。精听两步法：第一遍做题，第二遍对照挖空原文听写。
